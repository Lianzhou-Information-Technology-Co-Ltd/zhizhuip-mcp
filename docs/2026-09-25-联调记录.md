## 发现的问题

（联调中发现的文档缺陷或后端行为差异记在这里，并同步到设计文档第 11 节。）

1. 2026-09-26：请求不带语言头时，运行时默认发 `Accept-Language: *`；后端开了按语言头自动切换语言，解析不了 `*`，所有接口包括首页都返回空的 HTTP 500。MCP 已固定发 `Accept-Language: zh-CN`（`src/http.ts`），修复后 21 个只读工具全部走通。
2. 2026-09-26：子账号列表的动态产品分支有 2 分钟缓存，缓存键不含 `is_month`（后端 `Device::accountList`）。先查 dynamic-no-expiry，2 分钟内再查 dynamic-monthly，拿到的是永久产品的列表，再用这些 id 调期限产品的工具会报 subAccount not found。换 pagesize 避开缓存后，期限产品返回自己的子账号。2026-09-26 后端已在缓存键里加上 `is_month`，部署后复测。
3. 2026-09-26：优惠券列表在没有可用券时返回 code 0 "获取失败!"，MCP 会当成错误转给模型。
4. 2026-09-26：主账号流量两个动态产品返回的已用量 `use` 都是负数，期限产品的总量 `total` 也是负数。后端按本地记录的总量减上游剩余量计算已用量，两边数据对不上，待核对测试账号数据。
